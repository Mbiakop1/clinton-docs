====================================================================================================
OCI RESOURCE NAMING STANDARD  -  QUALIFIER GUIDE (cmr)
====================================================================================================

Version 1.0, 28 Sep 2026. Companion to OCI_Resource_Naming_Standard.txt (sections 6.5 and 8). This
guide answers one question: which qualifier, if any, do I put in a name, and which value do I
choose?

1. WHAT THE QUALIFIER IS
------------------------

   <org>-<env>-<rgn>-<type>-<app>[-<qual>]-<nn>
                                   ^^^^^^
   cmr-prd-cas-vm-cbs-ol-01          qualifier = ol  (Oracle Linux)
   cmr-prd-cas-vcn-cbs-01            no qualifier (VCN does not take one)

The qualifier is the optional sixth field. It says which variant of the resource type this is: the
OS family of a server, the tier of a subnet, whether a load balancer faces the internet, what a
bucket holds, and so on. The resource type decides everything: whether a qualifier is allowed, and
which values are allowed.

2. HOW TO DECIDE IN THREE STEPS
-------------------------------

   STEP 1  Find your resource type code in section 4 of this guide.
   STEP 2  Read the rule next to it:
             REQUIRED  -> you MUST add one value from the list shown.
             OPTIONAL  -> add one value from the list only if it helps tell
                          resources apart (see the "use when" note).
             NONE      -> do NOT add a qualifier. Go straight to <nn>.
   STEP 3  Pick exactly ONE value from the list (section 5). Use the
           "Choose it when" column. Never type anything that is not listed.

3. RULES THAT ALWAYS APPLY
--------------------------

  - Exactly one qualifier value, never two (not cmr-prd-cas-vm-cbs-ol-web-01).
  - Lowercase letters and digits only, 2 to 6 characters, taken from the lists in this guide.
  - No versions (ol8, win2022, 19c) in the names of servers or databases: an upgrade would make the
    name wrong. Only custom images (img) include the version, because images never change.
  - No free words: never new, old, final, temp, test, bak, copy, v2, primary, standby, dr, or a
    person's name.
  - Need to tell two resources apart and the type takes no qualifier? Use the next nn (01, 02...),
    or ask for a sub-application code (for example cbsbt = core banking batch). Do not invent a
    qualifier.
  - A resource and its DR copy use the SAME qualifier. Only the region field changes (cas -> jnb).
  - Need a value that is not listed? Ask the Cloud CoE to add it to the registry. The validator
    rejects anything unlisted.

6. COMMON QUESTIONS
-------------------

Q: A VM runs Windows and hosts the web tier. Where does "web" go?
A: Nowhere in the name: VMs take only the OS family (win). If you need the role in the name, ask for
   a sub-application code (for example cbsweb) and use it in the app field.

Q: My VM was upgraded from Oracle Linux 8 to 9. Do I rename it?
A: No. The qualifier is ol (family), so the name stays correct.

Q: A load balancer is used by partners over VPN, not the internet. ext or int?
A: ext. Anything reachable from outside the bank's own networks is external.

Q: I need two VCNs for the same application. The VCN takes no qualifier.
A: Use the sequence number: cmr-prd-cas-vcn-cbs-01 and cmr-prd-cas-vcn-cbs-02.

Q: I need a bucket for both logs and backups.
A: Create two buckets: cmr-prd-cas-bkt-cbs-log-01 and cmr-prd-cas-bkt-cbs-bkp-01.

Q: The DR copy of a production database in Johannesburg?
A: Same qualifier, only the region changes: cmr-prd-cas-dbs-cbs-rac-01 ->
   cmr-prd-jnb-dbs-cbs-rac-01.

Q: None of the values fit my resource.
A: Do not invent one. Ask the Cloud CoE to add a value to the registry (normally within five working
   days).
